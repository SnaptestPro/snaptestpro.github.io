Institute ke liye SmarTest Pro

Ye page institute owner aur demo dene wale ke liye hai. Students ke liye yahan kuch nahi.

Note: Is page par diye gaye features repo mein maujood code par based hain. Naye features (Result Tools, Fee Due, Daily Challenge, anti-cheat record) ko institute ke phone par pehle khud check karein, phir kisi ko dikhayein. Kuch features (jaise OMR scan) ke liye alag setup lagta hai.

SmarTest Pro kya karta hai

  • Practice aur exam tests: question bank se test banayein, time aur marks set karein, publish karein. Students offline bhi test de sakte hain; data baad mein sync hota hai.
  • OMR answer-sheet scan: OMR sheet se marks nikalne ka flow (scanner setup ke saath).
  • Results, rank aur leaderboard: test ke baad rank, scores aur leaderboard.
  • Batch, attendance aur CSV import: batch banayein, students CSV se jodein, batch-wise attendance rakhein.
  • Notifications: admin se students ko notification; app band ho to bhi milti hai.
  • Result Tools (naya): top-3 topper card image (download aur share), parent ke liye WhatsApp message (copy ya khud bhejna; auto-send nahi), class analytics (average, sabse galat sawal, chapter-wise kamzori, inactive students).
  • Fee Due (naya): batch ki fee ka pending list, due date, per-student WhatsApp reminder, cash "mil gaya" entry, aur batch notification (ek due date par ek baar).
  • Daily Challenge (naya): students ke liye roz 5 sawal aur 10 galti ka revision.
  • Institute ka apna APK: alag naam aur logo wali Android app (owner panel se).

Kya SmarTest Pro abhi nahi karta

  • Cloud Functions nahi hain, isliye notification aur fee reminder admin ke button dabane se jaate hain, apne-aap nahi.
  • Anti-cheat sirf record karta hai; koi test band nahi hota aur koi "proof" nahi banta.
  • Daily challenge ki streak phone par hi rehti hai.
  • Parent report mein attendance abhi nahi hai.
  • Online fee payment (UPI gateway) abhi nahi jud raha; fee cash ya bahar se jama hoti hai aur admin entry karta hai.

2 minute demo script

Ek admin account aur ek student account pehle se taiyar rakhein. Phone aur laptop dono khule hon to behtar.

  1. 0:00–0:20 — Parichay. "Ye aapke institute ka apna app hai, students ke phone par. Aaj hum 2 minute mein dekhenge ki test se lekar fee tak kya hota hai." Admin login karein.
  2. 0:20–0:50 — Batch aur fee. Batch kholein, ek batch ki fee aur due date dikhayein. Students CSV se jodne ka ek line mein bataayein. Attendance tab ek nazar mein.
  3. 0:50–1:10 — Test aur student. Question bank se ek test publish dikhayein. Student phone par "Aaj ka Challenge" card dikhayein; 1-2 sawal dekar result dikhayein.
  4. 1:10–1:30 — Result Tools. Records → Result Tools. Topper card download karke dikhayein. Parent tab par WhatsApp message dikhayein (sirf dikhayein, bhejein tabhi jab parent ki ijazat ho). Analytics ki ek list (sabse galat sawal) dikhayein.
  5. 1:30–1:50 — Fee Due. Batch Admin → Fee Due: pending list, ek reminder link, "Mil gaya" ka button, aur batch notification ka confirm.
  6. 1:50–2:00 — Band karte hue. Privacy aur Terms ka link dikhayein. Institute ka APK ya home-screen install ka tareeka batayein. Agla kadam: pehle din ki checklist.

Demo mein test data hi use karein. Kisi asli student ka number ya marks projector par na dikhayein.

Pehle din ki checklist (institute owner)

  1. Contact details badlein. Aaj app-config mein support WhatsApp, email aur hours developer ke hain. Apne institute ke numbers daalein, phir hi students ko app dein.
  2. Institute ka naam aur logo. Brand settings check karein; APK chahiye to Owner Panel se request karein.
  3. Privacy aur Terms. Dono pages ka institute appendix apni details se bharein aur qualified CA ya lawyer se check karwayein. Ye legal advice nahi hai.
  4. Guardian ki sahmati. 18 se kam students ke liye parent ki sahmati ka tareeka tay karein (registration form mein confirmation hai, par institute ki apni prakriya bhi zaroori ho sakti hai).
  5. Test batch. Khud ko ek test student banakar ek batch mein jodein. Ek test publish karke apne phone se dein. Result, rank aur topper card check karein.
  6. Fee. Test batch par fee aur due date daalein. Pending list dekhein. Ek cash entry karke check karein.
  7. Notification. Pehle khud ko notification bhejein; phone par aaye to hi students ko bhejein.
  8. Parent message. Ek student par parent report banaye; WhatsApp par sahi number khulta hai ya nahi, dekhein. Galat number ho to pehle theek karein.
  9. Phone par install. Browser se app kholein, home screen par add karein, aur ek baar offline test karke dekhein.
  10. Backup. Pehle hafte ke important results ka screenshot ya export apne paas rakhein.
  11. Students ko batayein. Ek chhota sa message taiyar karein: login kaise karna hai, aur kisi galti par kisse poochna hai.
